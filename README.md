# 💲📊 Data Warehouse Sales Analysis (SQL Server)

This warehouse sales analysis project is built to explore and analyze sales data stored in a data warehouse.
It demonstrates advanced SQL techniques for extracting insights on sales performance, customer behavior, and product profitability using SQL Server.

---

## ⚙️ Key Processes

- Explored warehouse schema and structure using INFORMATION_SCHEMA views
- Performed Exploratory Data Analysis (EDA) on customers, products, and sales
- Calculated key business metrics (sales, orders, customers, products)
- Used aggregations, joins, and window functions for advanced analytics
- Ranked top-performing products and customers
- Conducted time-based, cumulative, and year-over-year (YoY) trend analyses
- Segmented customers and products using CASE logic

---

## 🔍 Key Findings

✅ Date Range: Orders span from Dec 2010 to Jan 2014 (4 years of data)

✅ Total Sales: $29.36M across 27,659 orders and 60,423 items sold

✅ Customers: 18,484 unique customers, mainly from the United States

✅ Age Range: Youngest customer is 39, oldest is 109

✅ Top Category: Bikes dominate with 96% of total revenue

✅ Most Products: Found in the Components category

✅ Best Seller: Mountain-200 product line

✅ Peak Year: 2013 achieved the highest sales

✅ Top Month: December shows the strongest sales performance

✅ Customer Segmentation: Most customers are new (less than 12 months history)

---

## 🛠️ Technology Used

- SQL Server — for querying and analytics
- Star Schema Warehouse — with dim_customers, dim_products, and fact_sales
